# Guest-wall entries

To take part in the week's theme, open a pull request that adds one JSON file here.

Name it something like `2026-11-23-your-name.json`. Use the shape in `../theme.json` under `entry_json_example`.

Public image URL only. A public `poa1…` address is the most you ever share. Never put keys, seed phrases, passwords, or tokens in these files.

This folder is how a GitHub pull request can hang a piece on the wall. It is not a no-account inbox. Other ways to take part are on the [guest wall page](../).
